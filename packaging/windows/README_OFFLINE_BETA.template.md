# 病历助手 Windows 离线内测包

版本：{version}

## 包含内容

- 浏览器扩展：`extension/`
- 本地语音服务：`server/`
- Python 运行环境：`runtime/python/`、`.venv/Lib/site-packages/`
- 中文语音识别模型（批量、流式、语音活动检测）：`models/modelscope/`
- 启动器：`BingliAssistant.exe`

语音和病历内容只在本机处理，不会上传。

## 第一次使用

1. 双击桌面上的“病历助手”图标（或本文件夹里的 `BingliAssistant.exe`）。
2. 屏幕右下角会出现一个小圆点图标（可能收在“^”折叠区里）：
   - 黄色：正在启动并加载语音模型，通常需要 1～2 分钟，请耐心等待（变绿后第一次听写不会再卡顿）；
   - 绿色：已就绪；
   - 灰色：服务已停止；
   - 红色：出错（例如端口被其他程序占用）。
3. 就绪后会自动打开“病历助手”窗口（没有地址栏的独立窗口）。不需要安装浏览器扩展。关闭窗口不会停止服务，也等于退出登录；托盘图标右键“打开听写页面”可以重新打开。
   如果电脑上没有 WebView2 运行时（Windows 11 自带，多数更新过的 Windows 10 也有），会自动改在默认浏览器里打开同一个页面（`http://127.0.0.1:8765/app/`），功能一样。
4. 第一次打开听写页面时，先设置管理员账号，再由管理员为每位医生添加账号；之后每位医生用自己的账号登录，用完点“退出登录”，暂时离开点“锁定”。详见 `docs/LOCAL_ACCOUNTS.md`。
5. 浏览器会询问是否允许使用麦克风，请选择“允许”（只需一次）。登录后开始听写。

> 以前版本需要在 Edge/Chrome 里加载 `extension` 文件夹。现在不需要；`extension` 文件夹仍保留，供需要在浏览器扩展里使用的场合。

## 用完以后：停止服务

任选一种：

- 在听写页面右上角点“停止服务”；
- 在屏幕右下角的托盘图标上右键，选“停止服务并退出”；
- 在状态页面（`http://127.0.0.1:8765/`）点“停止服务”。

停止后，草稿仍保留在听写页面里。需要继续使用时，再双击桌面“病历助手”图标即可。

关闭浏览器页面不会停止服务。托盘菜单里的“退出托盘（保持服务运行）”只关闭图标，服务继续运行。

## 常见问题

**图标变红，提示端口 8765 被占用**
有别的程序占用了这个端口。病历助手不会去结束其他程序。请关闭占用端口的程序，或联系技术支持。

**一直黄色，或提示启动失败**
在托盘图标上右键，选“打开日志文件夹”，把 `service.log` 和 `launcher.log` 发给技术支持。日志记录服务的运行信息和错误，不主动记录录音和病历正文。

**听写页面显示“本地服务未启动”**
双击桌面“病历助手”图标启动服务。

## 排查工具（一般用不到）

- `check_service.bat`：显示服务状态；
- `start_server_offline.bat`：以可见窗口启动服务，方便看错误信息；
- `stop_server.bat`：停止服务。

## 内测反馈

- 听写页面里的“内测反馈”只保存在本机：`server/data/feedback.jsonl`；
- 反馈内容请不要包含患者姓名、身份证号、住院号等敏感信息。
