# 病历助手本地 ASR 测试清单

更新时间：2026-08-11

## 1. 启动前

1. 双击或运行 `start_server.bat`。
2. 打开插件页面。
3. 点击“环境自检”。

自检重点看：

- Python 依赖：应为“通过”。
- 医学词库：应显示已启用热词。
- 医学后处理：应显示已加载纠错规则。
- 模型包：源码开发目录下可能显示“提醒”；如果语音可正常识别，可暂时忽略。离线分发包中应能定位到模型目录。
- 麦克风权限：首次录音时需要允许。

## 2. 识别模式测试

分别测试三种模式：

- 快速：短句、低延迟。
- 均衡：默认建议。
- 准确优先：医学术语多、长句较多时测试；CPU 电脑会更慢。

每次识别后记录：

- RTF 值；
- 是否有音量/削波提醒；
- 热词数量；
- 医学纠错命中数；
- 手动修改最多的词。

## 3. 分段识别测试

建议朗读 20-40 秒，中间自然停顿 1 秒左右，例如：

> 患者发热五天，最高体温三十九摄氏度。停顿。外院血培养提示肺炎克雷伯杆菌，予梅罗培南治疗。停顿。入院后完善 PCT、CRP、mNGS 检查。

预期：

- 页面提示“检测到 N 个语音段”；
- “识别结果轨迹”显示原始识别与后处理结果；
- 常见误识别被保守修正，例如“梅罗培南 → 美罗培南”“肺炎克雷伯杆菌 → 肺炎克雷伯菌”；
- 最终文本合并到病历草稿。

## 4. 反馈诊断

点击“内测反馈”时，诊断信息会附带：

- 插件版本；
- 本地服务状态；
- 自检结果；
- 最近一次识别的 RTF、分段数、纠错数、质量提醒；
- 浏览器麦克风状态。

诊断信息不包含病历正文、录音文件、原始识别文本。
