## 1. 目的

病历助手的词库只用于语音识别的热词提示、保守的术语规范化和提交前核对提醒。
本政策规定词库内容可以从哪里来、怎样处理、谁来审核，以降低版权、隐私和临床误导风险。

基本原则：

- 只收录术语本身（词、短语、常用写法），不复制成段的受版权保护文字；
- 不收录、不保存任何患者身份信息或真实病历正文；
- 词库不包含诊断标准、参考范围、治疗方案或剂量建议；
- 每个词库包可追溯到明确来源，并有审核人；
- 词库不是医学知识库，词库命中不代表内容正确，所有内容仍由医生核对。

## 3. B 级：需人工审核后使用

- 国内诊疗指南、规范、教材中的术语；
- 医院或科室内部常用写法；
- 医生提供的去标识化文本片段。

要求：

1. 只摘取术语，不整段复制；
2. 入库前由对应专业的医生审核并登记；
3. 来自医生文本片段的，必须先去除姓名、证件号、住院号、日期等可识别信息；
4. 登记来源名称，无法说明来源的内容按 C 级处理。

## 4. C 级：不得使用

- 含患者身份信息或真实病历正文的材料；
- 论坛、社交媒体（如 Reddit）、聊天记录等来源不明的内容；
- 未获授权批量抓取的网页、付费数据库和书籍内容；
- 来源或许可证无法说明的词表；
- 由语言模型凭空生成、且未经 A/B 级来源核对和医生审核的词表。

## 5. 专业词库包的准入要求

每个专业词库包（如呼吸与危重症科、骨科）上线前必须满足：

1. 有清单文件，登记：包 id、专业、版本、来源条目、整理日期；
2. 每个词条可追溯到 A 级或经审核的 B 级来源；
3. 由该专业的医生审核，登记审核人与审核日期；
4. 状态为“已审核”（reviewed）后才可默认启用，“草稿”（draft）状态的包默认不启用；
5. 药名使用通用名，不收录商品名；
6. 发音相近、含义不同、临床后果严重的词（如不同药物、左右侧、否定词）需单独标注，由医生确认是否保留。

## 6. 用户自定义词库与个人学习数据

- 用户自定义热词和“从修改中学习”记录只保存在本机，不上传；
- 个人学习只保存“识别结果 → 医生修正”的词对，不保存病历上下文；
- 个人学习默认关闭，医生可随时一键清除；
- 导入他人词库前，医生应自行确认其来源合规。

## 6.1 本院病历统计（H 级，医院自己提取）

医院可以用听写页面“热词”页的“从本院病历提取热词”对本院病历做词频统计，得到本科室的候选词，医生在页面里勾选后生成词库：

- 病例只发送给本机服务、只放在内存里（关闭窗口即清除），**不上传、不联网、不写磁盘、不进入本仓库**；跨出内网的只有医生核对过的词表；
- 词必须出现在不少于 N 份不同病例中（默认 5，N 的取值请与医院信息科/伦理确认），不含数字、证件号、电话和识别出的姓名；
- 生成的词库清单中来源登记为 H 级，状态默认为“草稿”；医生核对并登记审核人后才可默认启用；
- 医生应在带出内网之前通读词表；词表和候选表按医院的数据管理规定保管。

使用方法和局限见 `server/hotword_miner/README.md`。

## 7. 变更记录要求

新增或修改词库包时，同步更新 `server/data/hotword_packs/SOURCES.md`：写明日期、来源、处理方式、新增内容和使用范围。
