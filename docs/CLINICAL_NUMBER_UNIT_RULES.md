## 3. 核实过的规则

### 3.1 国家规范（S1）

- 第九条：病历书写一律使用阿拉伯数字书写日期和时间，采用 24 小时制记录。
- 第五条：通用的外文缩写和无正式中文译名的症状、体征、疾病名称等可以使用外文。

### 3.2 数字与单位的国家标准要求（来自 S2 的转述）

1. **计量用阿拉伯数字**：量 = 数值 × 单位，数值用阿拉伯数字，单位用符号，写在数值之后。例：`523.56 km`、`605 g`、`12 d`、`220 V`、`120 dB`。S2 称这与 GB 3101—1993、GB/T 1.1—2009 一致。
2. **计数、百分数、比例、概数也用阿拉伯数字**：例 `34.05%`、`5 个月`、`20 余次`、`约 70 岁`。
3. **不得滥用阿拉伯数字（“得体”原则）**：`12 指肠`、`3 角形` 都不得体。判断“一”能否改成“1”的办法：用其他数字去替换，说得通才能改。例“张三忙碌了一天”可写“1 天”，“李四一天忙到晚”不能写“1 天忙到晚”。
4. **必须用汉字数字的情形**：
   - 长期稳定的固定词语：`十二指肠`、`三叶虫`、`二尖瓣`（同类）、`星期四`、`另一方面`；
   - **数字连用的概数和含“几”的概数**：`三四天`、`一两小时`、`七十三四岁`、`几十`、`九十几`；
   - 非公历纪年。
5. **数值范围**：用浪纹线 `～`；前后单位或附加符号相同时，**前一个可省略**，如 `10～15 km`、`410～445 页`、`－39～－9 ℃`；百分数不能省：`25%～35%`（不写 `25～35%`）。
6. **小数**：纯小数必须写出小数点前的 `0`（`0.92`，不写 `.92`）。
7. **多位数分节**：每 3 位一组，组间留小空隙（`23 456`），年号四位数除外。
8. **阿拉伯数字与汉字数字只允许“万”“亿”连用**：如 `2.53 万`，不写“2 万 5 千 3 百”。
9. **计数单位不是计量单位**：`个`、`次`、`例` 等是计数单位，数值常写为不带单位的纯数。
10. **例子中的空格情况**（S2 引用的标准示例）：`523.56 km`、`605 g`、`12 d` 数值与单位之间有空格；`34～39 ℃` 中 `℃` 之前有空格；`40°`、`34.05%` 紧贴。

> 注意：按 S2 引述的标准示例，`℃` 前有空格。而 D1 决定 `℃` 紧贴，这与真实病历写法（见 3.3）一致，但与出版物标准的字面示例不同。病历不是出版物，已按 D1 执行；此处记录差异。

### 3.3 真实病历样例中的写法

**生命体征**

| 样例 | 来源 |
|---|---|
| `T 36.5℃   P 98 次/分    R 28 次/分    BP 130/70 mmHg` | S3 |
| `T36.5℃ P60 次/分 R 22 次/分 BP 150/90mmHg` | S4 |
| `T：36.3℃ P：70 次/分 R：20 次/分 BP:130/50mmHg` | S4 |
| `血压18/11kPa(135/82mmHg)`（旧式，kPa 与 mmHg 并列） | S4 |

→ **真实病历的空格并不统一**：有的 `BP 130/70 mmHg`，有的 `BP 150/90mmHg`。因此不存在可直接照抄的“事实标准”，D1 就是本项目自己的统一规则。

**检验与检查**：`红细胞 5.5×10^12/L`、`血红蛋白 160 g/L`、`白细胞 8.9×10^9/L`、`血红蛋白88g/L`、`WBC 17.8×10^9/L，N 83.9%`（S3、S4）。

**时间与程度**：`15 年`、`1 周`、`10 余年`、`半年`（S3）；`心功能Ⅲ级`、`2/6 级`、`Ⅰ度凹陷性水肿`（S3）；`肝肋下触及 2 cm，剑突下 3 cm`（S3）。

**剂量**：`云南白药0.5qid`、`白芨粉6g bid`、`络血注射液10mg肌注，bid`（S4）。

**骨科**
- 关节活动度：度数符号 `°` 紧贴数字，范围用连字符：`70-90°`、`50-60°`；以中立位为 0° 记录（S5）。
- `直腿抬高不足 70°`、`胫骨前移比健侧大 5 mm 为阳性`（S9）。
- 专科检查的记录顺序：望诊、触诊、叩诊、听诊、关节活动、肌力、测量（肢体长度、周径，需双侧对比）、特殊试验、神经功能、血管检查（S6）。

**呼吸与危重症**
- `PEEP 一般的设定值为5cmH2O`、`潮气量 6-8 ml/kg`、`吸呼时比 ≤1：2`（S8）。
- `FEV1 占预计值的 45.2%`、`FEV1/VC 实测值为 79.1%`、`FVC 占预计值百分比为 82.5`（S7）。

→ 这些来源中 `cmH2O`、`ml/kg` 的空格同样不统一。

**仅来自搜索摘要、未读正文的**：血气分析指标 `PaCO2 35-45 mmHg`、`氧合指数 PaO2/FiO2 <300mmHg`，以及呼吸机参数示例中的 `潮气量530 ml`、`支持压力28 cmH₂O`。写法同样不统一。

## 4. 本项目的书写规则（草案）

### 4.1 数值

| 规则 | 示例 |
|---|---|
| 数值用阿拉伯数字 | `一百三十` → `130` |
| 小数写出前导 0 | `零点五` → `0.5` |
| 负数 | `负二点五` → `-2.5` |
| 阿拉伯数字不与汉字数字混写（“万”“亿”除外） | 不写 `2 千` |
| 数值范围用 `-`（D4） | `五到十毫克` → `5-10 mg` |

### 4.2 单位书写样式（D1）

**紧贴数字**：`℃`、`%`、`次/分`、`mmHg`，以及以 `×10^` 开头的单位（如 `12.3×10^9/L`，现有行为）、`秒`/`s`（现有行为）。
`°`（度）紧贴数字（D5）：与 S2 引述的标准示例 `40°` 和骨科来源（S5）一致。

**数字与单位之间空一格**：其余所有单位，如 `mg`、`g`、`μg`、`mL`、`L`、`kg`、`cm`、`mm`、`m`、`mmol/L`、`μmol/L`、`g/L`、`mg/L`、`ng/mL`、`U/L`、`IU/L`、`cmH2O`、`L/min`、`kPa`、`mL/kg`。

**带单位的用药频次**：剂量与频次之间空一格，`30 mg tid`、`1 g q8h`（现在会粘成 `mgtid`，属缺陷）。

### 4.3 转换范围（D2）

**转换**：
- 数字紧跟已知单位：`五十毫克` → `50 mg`；
- 已知指标名后的数字：`血钾三点五` → `血钾 3.5`；
- 名字后的数字后面不能再接汉字（`体重三个月`、`尿量三天` 不转换，避免吞掉时间与计数词）；
- 药名等汉字后面紧跟“空格样式”的数量时，补一个空格：`美罗培南 1 g`；
- 血压：名字（血压、BP，且前面不是“高”“低”）或毫米汞柱 + 数字才处理；没有口述单位时补 `mmHg`；
- 口述的 `度` 只在体温（→ `℃`）和关节角度名（屈曲、伸直、外展、直腿抬高试验等，→ `°`）后转换，`三度房室传导阻滞` 不动。

**不转换**：
- 概数与含“几”的数：`三四天`、`一两周`、`几十`；
- 固定词语：`二尖瓣`、`三叉神经`、`十二指肠`、`一周`、`一天`；
- 级别、分型、评分中的汉字数字（D7）：`肌力四级`、`心功能三级`、`VAS评分五分`；
- 编号、日期与年份（ASR 本身常输出数字，不重复处理）。

### 4.4 歧义处理（D3）

不转换、保留原话，并在核对栏提示“数字未规范化，请核对”的情形：
- 有多种合理拆分：同一句话能拆成两组以上都说得通的数；
- 没有任何合理拆分：如血压拆出来的舒张压或收缩压超出合理范围；
- 数值超出该指标的合理范围（体温、血氧等），或单位与指标不匹配。

**血压的拆分办法**（范围约束，而不是死记短语）：
1. 把口述的数字串拆成“收缩压 | 舒张压”两个数；
2. 只保留收缩压大于舒张压，且两者都落在合理范围内的拆法；
3. 恰有一种拆法时转换，如 `一百二十八十` → `120/80 mmHg`（另一种拆法 `128|10` 的舒张压不合理）；
4. 零种或多种时不转换并提示；
5. 只说一个数（`一百三十毫米汞柱`）时输出 `130mmHg`，**不补出另一个数**，也不假定它是血压。

合理范围的具体数值需要由医生确认（D8）；当前暂定收缩压 50–300、舒张压 20–200（`measures.json` 中标为 provisional），它只用来判断“能不能这样拆”，不是临床阈值。

### 4.5 需要登记的内容（数据文件，不写在代码里）

1. **单位表**：口述写法 → 符号 → 书写样式（紧贴或空格）。例：`毫米汞柱 → mmHg（紧贴）`、`毫摩尔每升 → mmol/L（空格）`、`厘米水柱 → cmH2O（空格）`。
2. **指标名表**：指标名 → 默认单位 → 合理范围（仅用于提示）。呼吸与危重症、骨科的指标名需要医生审核。
3. **歧义与提示文案**。

## 6. 已知限制

1. **ASR 原始输出没有实测。** 仓库里的纠错规则显示模型常直接输出阿拉伯数字（如 `3年`、`mmHg`），但不同医生、不同句子的原始输出分布没有数据。规则按“中文数字和阿拉伯数字都可能出现”处理；医生真实口述的原始识别结果仍需采集，补充到测试集。
2. **指标名表和单位表是草稿**，呼吸与危重症、骨科的名单待医生审核；表里没有的指标，其数字不会被转换（D2 的代价）。
3. **血压合理范围暂定**（D8）。
4. **单个血压值**（`血压一百三十`）输出 `血压130mmHg`，不假定另一个数；单个数值落在合理范围外时不转换。
5. **身高的口语写法**（`一米七`）不猜，保持原样。
6. 日期、时间、年份由 ASR 自己输出，本模块不处理。
7. 一个名字后紧跟不在名单里的汉字单位（如 `体重六十五斤`）：数字不转换。
8. 旧的检验指标规则（白细胞、CRP、肌酐等约 30 个名字）仍保留在 `server/app.py`，新旧两套规则并存，新增指标优先加到 `measures.json`。
